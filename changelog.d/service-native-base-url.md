- **Installing or regenerating the background service now keeps `CODEX_NATIVE_BASE_URL`.** The macOS plist, the Linux unit, and the Windows `start-codex-router.cmd` launcher were written from a fixed variable list, so a native GPT base URL pointed at another local proxy disappeared on every reinstall and native turns silently went straight to chatgpt.com. A plain `http(s)` URL present at install time is now written into all three; anything else is left out.
